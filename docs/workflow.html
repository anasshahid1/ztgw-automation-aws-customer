ZTGW Terraform Deployment Workflow

What happens when you run terraform apply -var-file=ztgw-full-deploy.tfvars

flowchart TD
    Start(["👤 You run:
terraform apply -var-file=ztgw-full-deploy.tfvars"]):::userAction

    Start --> Input

    subgraph Input [" 📝 STAGE 1 — Configuration "]
        direction TB
        I1["ztgw-full-deploy.tfvars
gateway name, region, VPC/subnet IDs,
Zscaler creds, AWS account to whitelist"]:::config
    end

    Input --> Glue1

    subgraph Glue1 [" ⚙️ STAGE 2 — Terraform writes the order form "]
        direction TB
        G1["local_file.ztgw_input
builds JSON payload from your .tfvars
writes → .ztgw-input.json"]:::terraform
    end

    Glue1 --> Glue2

    subgraph Glue2 [" 🤖 STAGE 3 — Terraform launches the script "]
        direction TB
        G2["null_resource.ztgw
(local-exec provisioner)
runs scripts/deploy_ztgw.sh
⚠️ only during apply, never during plan"]:::terraform
    end

    Glue2 --> Zscaler

    subgraph Zscaler [" ☁️ STAGE 4 — Zscaler REST API (inside deploy_ztgw.sh) "]
        direction TB
        Z1["🔑 Authenticate via OAuth2
(client_id + client_secret)"]:::zscaler
        Z2["🔍 Check if gateway already exists
by name"]:::zscaler
        Z3["✨ Create new ZT Gateway
(region, AZs, whitelisted account)"]:::zscaler
        Z4["⏳ Poll every 15s
until health = HEALTHY
(can take several minutes)"]:::zscaler
        Z5["⚡ Force activation"]:::zscaler
        Z1 --> Z2 --> Z3 --> Z4 --> Z5
    end

    Zscaler --> Glue3

    subgraph Glue3 [" 📨 STAGE 5 — Script writes the receipt "]
        direction TB
        G3["writes result to
.ztgw-output.json
(gateway_id, endpoint_service_name, health)"]:::terraform
    end

    Glue3 --> Read

    subgraph Read [" 📖 STAGE 6 — Terraform reads the receipt "]
        direction TB
        R1["data.local_file.ztgw_output
reads .ztgw-output.json"]:::terraform
        R2["local.endpoint_service_name
extracted for use below"]:::terraform
        R1 --> R2
    end

    Read --> AWS

    subgraph AWS [" 🟧 STAGE 7 — AWS resources created "]
        direction TB
        A1["aws_vpc_endpoint
GatewayLoadBalancer type
in your existing VPC, both subnets"]:::aws
        A2["data.aws_route_table
auto-discovers route table
for each subnet"]:::aws
        A3["aws_route
0.0.0.0/0 → GWLB Endpoint
(one per subnet's route table)"]:::aws
        A1 --> A2 --> A3
    end

    AWS --> Done(["✅ Done
Gateway + VPC Endpoint + Routes all live"]):::doneNode

Color Legend

ColorMeaning
BlueYour input — the .tfvars file you edit
PurpleTerraform's own automation glue (writing/reading files, launching the script)
OrangeZscaler cloud — the actual API calls happening remotely
GreenAWS resources being created — the real infrastructure
Bright GreenFinal result

Everything from Stage 2 through Stage 7 happens automatically inside one terraform apply run — you only interact with Stage 1 (editing the .tfvars file) and watch Stage 4 happen (the health-check polling can take a few minutes and prints progress to your terminal).
